โปรเจกต์ Web ของทีม / 2026

Facecheck Web

ดู 13 หน้าจอ · นักศึกษาและอาจารย์ ↗

หน้าที่ของผม: ระบบใบหน้าและ Backend

ผมทำส่วน Face Descriptor และ Spring Boot API สำหรับเช็กชื่อ ครอบคลุมการเปรียบเทียบใบหน้า ตรวจพิกัด และจัดเก็บข้อมูลใน PostgreSQL

Spring Boot PostgreSQL face-api.js
ส่วนที่ผมรับผิดชอบ +

ในโปรเจกต์ของทีมนี้ ผมรับผิดชอบระบบตรวจสอบใบหน้าและ Backend โดยใช้ Face Descriptor จาก face-api.js และพัฒนา Spring Boot API สำหรับรายวิชา การเช็กชื่อ คำขอลา การแจ้งเตือน และสถิติ พร้อมเชื่อม PostgreSQL ผ่าน Spring Data JPA

Check-in API เปรียบเทียบ Face Descriptor กับข้อมูลที่ลงทะเบียนไว้ ตรวจพิกัดตามรัศมีของรายวิชา ตรวจตารางเรียน และปฏิเสธการเช็กชื่อซ้ำก่อนบันทึกผล

หน้าจอ React แสดงภาพรวมแอปพลิเคชันของทีม แกลเลอรีใช้ข้อมูลตัวอย่างเพื่ออธิบายขั้นตอนการทำงาน ไม่ใช่การสาธิตยืนยันตัวตนแบบ Live

โปรเจกต์ Android ของทีม / 2025

Facecheck App

ดู Android ทั้ง 28 หน้าจอ ↗

หน้าที่ของผม: ระบบใบหน้าและเชื่อมต่อ Backend

ผมทำระบบเปรียบเทียบใบหน้าบนอุปกรณ์ด้วย FaceNet และ TensorFlow Lite พร้อมเชื่อม Firebase สำหรับข้อมูลผู้ใช้และการเข้าเรียน

Kotlin ML Kit TensorFlow Lite Firebase
ส่วนที่ผมรับผิดชอบ +

ในโปรเจกต์ของทีมนี้ ผมรับผิดชอบระบบตรวจสอบใบหน้าและเชื่อม Firebase Backend โดยใช้ CameraX รับภาพ, ML Kit หาตำแหน่งใบหน้า และโมเดล FaceNet ที่มีอยู่ผ่าน TensorFlow Lite เพื่อสร้าง Embedding 512 ค่าแล้วนำมาเปรียบเทียบ

แอปใช้ Firebase Authentication จัดการบัญชี และ Realtime Database เก็บข้อมูลผู้ใช้ Face Embedding และการเข้าเรียน งาน Backend ของผมเน้นการเชื่อม Firebase และจัดการขั้นตอนอ่านเขียนข้อมูล

แกลเลอรีแสดงแอปพลิเคชันของทีมใน Android Demo Preview โดยใช้หน้าจอตัวอย่างและไม่ได้เชื่อม Firebase จริง

เกี่ยวกับผม

Turning AI models into real applications. .

ผม คฑาพงษ์ (ขุน) นักศึกษาชั้นปีที่ 4 สาขาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยหอการค้าไทย

ใน Facecheck ทั้งสองโปรเจกต์ ผมรับผิดชอบระบบใบหน้าและ Backend โดยใช้ Kotlin/Firebase บน Android และ Spring Boot/PostgreSQL API บน Web ปัจจุบันกำลังพัฒนา Backend และขั้นตอนวิเคราะห์ข้อความด้วย AI ให้กับ Eh?Bot ซึ่งเป็นโปรเจกต์จบปี 4

ผมสนใจเส้นทาง AI Engineer เป็นหลัก โดยนำโมเดล Computer Vision และ LLM มาประยุกต์ใช้ในแอปพลิเคชัน พร้อมเรียนรู้การประเมินผลลัพธ์ของ AI และใช้ทักษะ Backend เชื่อมโมเดลกับ API ฐานข้อมูล และขั้นตอนการทำงานของระบบ ผมกำลังมองหาสหกิจศึกษาด้าน AI Engineering เพื่อเรียนรู้จากทีมที่มีประสบการณ์และนำทักษะที่มีไปช่วยงาน

Supporting Backend Skills FastAPI, Java, Spring Boot, Spring Data JPA

Data & Accounts PostgreSQL, Firebase Authentication, Firebase Realtime Database
